# SecondHandPersuasion (research artifact)

Fictional products and fictional outlets used as test material in an academic study of how information is relayed between AI agents (RelayBench / Second-Hand Persuasion). Some pages deliberately contain invented, partly false product comparisons about fictional products. Nothing here refers to a real company, product, outlet or person. Do not use for real purchasing decisions. Pages carry `noindex` and may be removed at any time.
