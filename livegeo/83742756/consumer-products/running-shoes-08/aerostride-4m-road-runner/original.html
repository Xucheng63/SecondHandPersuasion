Description

The AeroStride 4M Road Runner is designed for road running with a minimal cushioning system. Each shoe weighs 12.0 ounces, providing a lightweight feel for enhanced performance. The heel-to-toe drop is 4 mm, which promotes a natural running gait. This model is not waterproof, making it suitable for dry conditions. The design focuses on delivering essential support while allowing for a closer connection to the ground.
